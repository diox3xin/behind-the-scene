# 🎬 Behind the Scenes - Расширение для SillyTavern

Полный пакет расширения создан и готов к установке!

## 📦 Содержимое

### Основные файлы
- **manifest.json** - Манифест расширения для SillyTavern
- **index.js** - Основная логика расширения (288 строк)
- **style.css** - Стили интерфейса

### Документация
- **README.md** - Полное описание расширения
- **QUICKSTART.md** - Быстрый старт за 3 шага
- **INSTALLATION_RU.md** - Детальная инструкция по установке
- **EXAMPLES_RU.md** - Примеры использования и советы
- **LICENSE** - MIT лицензия

## 🚀 Быстрая установка

```bash
# Скопируйте всю папку в:
SillyTavern/public/scripts/extensions/third-party/sillytavern-behind-the-scenes/

# Перезапустите SillyTavern
# Активируйте расширение в настройках
```

## ✨ Возможности

✅ **Генерация интервью** - Персонажи дают "закулисные" интервью о сценах  
✅ **История интервью** - Все сохраняется автоматически  
✅ **Контекст сцены** - AI учитывает окружающие сообщения  
✅ **Удобный интерфейс** - Кнопка 🎬 на каждом сообщении  
✅ **Гибкие настройки** - Включай/выключай опции  
✅ **Кроссплатформенность** - Работает с любой моделью AI  

## 📊 Технические детали

- **Язык**: JavaScript (ES6+)
- **Зависимости**: SillyTavern API
- **Размер**: ~20 KB
- **Совместимость**: SillyTavern 1.10.0+
- **Лицензия**: MIT

## 🎯 Как использовать

1. Откройте чат с персонажем
2. Наведите на любое сообщение
3. Нажмите иконку 🎬
4. Читайте интервью!

## 📝 Что делает расширение

Расширение добавляет мета-уровень к вашим RP сессиям:
- Персонажи "выходят из роли" и обсуждают сцены как актёры
- Делятся эмоциями, трудностями съёмки, взаимодействием с партнёрами
- Дают инсайты о мотивации персонажа
- Создают эффект "бонусного контента" как в настоящих фильмах

## 🎨 Основные компоненты

### index.js
- `loadSettings()` - Загрузка настроек из хранилища
- `saveSettings()` - Сохранение настроек и истории
- `generateInterview()` - Генерация интервью через AI
- `showInterviewPopup()` - Отображение интервью
- `updateInterviewList()` - Обновление списка интервью
- `addInterviewButtons()` - Добавление кнопок к сообщениям
- `createUI()` - Создание панели настроек

### style.css
- Стили для кнопок 🎬
- Стили всплывающих окон
- Стили списка истории
- Адаптивный дизайн
- Скроллбары
