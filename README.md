# 🎬 Behind the Scenes

Расширение для SillyTavern, которое позволяет персонажам давать "закулисные" интервью о сценах, в которых они "снимались".

## 📖 Описание

Представьте, что ваш чат с персонажами — это съёмки фильма или сериала, а персонажи — актёры, играющие свои роли. Это расширение позволяет вам "брать интервью" у этих "актёров" о сценах, которые они только что сыграли.

## ✨ Возможности

- 🎬 **Генерация интервью**: Нажмите на кнопку рядом с любым сообщением, чтобы получить интервью персонажа о этой сцене
- 💬 **Реалистичные ответы**: Персонажи отвечают как настоящие актёры, обсуждая свои эмоции, трудности и взаимодействие с партнёрами
- 📚 **История интервью**: Все интервью сохраняются и доступны для просмотра
- 🎯 **Контекстная осведомлённость**: Можно включить контекст сцены для более глубоких интервью
- 🎨 **Красивый интерфейс**: Всплывающие окна с удобным отображением интервью

## 🚀 Установка

1. Скачайте или клонируйте этот репозиторий
2. Поместите папку `sillytavern-behind-the-scenes` в директорию:
   ```
   SillyTavern/public/scripts/extensions/third-party/
   ```
3. Перезапустите SillyTavern
4. Расширение появится в настройках расширений

## 📝 Использование

### Создание интервью

1. Откройте чат с персонажем
2. Наведите курсор на любое сообщение
3. Нажмите на иконку 🎬 рядом с сообщением
4. Дождитесь генерации интервью
5. Наслаждайтесь "закулисным" взглядом на сцену!

### Настройки

В панели расширений вы найдёте:

- **Включить расширение**: Вкл/выкл функционал
- **Включать контекст сцены**: Добавлять контекст (сообщения до и после) для более детальных интервью
- **История интервью**: Просмотр всех сохранённых интервью
- **Очистить историю**: Удалить все интервью

### Просмотр истории

- Все интервью сохраняются в истории
- Нажмите "👁️ Посмотреть" чтобы открыть интервью
- Нажмите "🗑️ Удалить" чтобы удалить конкретное интервью

## 🎭 Примеры вопросов

Расширение генерирует интервью, в которых персонажи могут обсуждать:

- Эмоциональную подготовку к сцене
- Трудности в игре определённых моментов
- Взаимодействие с другими "актёрами"
- Импровизацию во время "съёмок"
- Личные переживания по поводу сюжета

## 🛠 Технические детали

- Использует API генерации SillyTavern
- Работает с любой подключённой моделью (OpenAI, Claude, локальные модели и т.д.)
- Интервью сохраняются в метаданных чата
- Не влияет на основной диалог
