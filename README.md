# 🎬 Behind the Scenes — мини-чат 2.1

Отдельное закулисное интервью по выбранной сцене SillyTavern. Вопросы и ответы **не добавляются в основной сюжетный чат**.

## Использование

1. Откройте чат и нажмите 🎬 у сообщения сцены. Окно появляется сразу, не ожидая загрузки карточек или ответа модели. Также есть кнопка «Интервью по последнему сообщению» в настройках расширения.
2. Выберите собеседников галочками: текущая персона, авторы сообщений сцены и упомянутые карточки подтягиваются автоматически. NPC из текста распознаются моделью в фоне. Можно добавить карточку или NPC вручную.
3. Введите вопрос или нажмите заготовку, затем «Спросить». Enter отправляет, Shift+Enter переносит строку. Заготовку можно отредактировать до отправки.
4. Один запрос генерирует короткий ответ всех выбранных участников, позволяя им реагировать друг на друга. По умолчанию: действие и 1–2 предложения на участника, 240 токенов **на весь ответ**.
5. Продолжайте разговор. История интервью доступна в настройках расширений → Behind the Scenes → «Открыть».

Лимит ответа регулируется от 80 до 800 токенов. Для нескольких участников его можно увеличить. Модель может не соблюдать желаемый формат; слишком низкий лимит может оборвать фразу, а reasoning-модели иногда тратят лимит на рассуждения.

Сцена и соседние сообщения фиксируются при создании интервью. Редактирование исходной сцены не меняет уже созданное интервью. В запрос входят выбранные участники, сцена, необязательные соседние сообщения и последние 20 сообщений мини-чата. Полная история сохраняется, но при очень большой сцене возможен выход за контекст модели.

### Автоматические участники

Без запроса к модели добавляются текущая персона (с описанием), авторы выбранного/соседних сообщений и карточки, чьи имена явно встречаются в тексте. Текущая персона всегда доступна для выбора, даже если не названа в сцене. Галочки можно снять.

По умолчанию при создании интервью выполняется **дополнительный запрос модели** для поиска NPC и других участников. Используется выбранный для интервью профиль подключения (при первом запуске — основной API). Это расходует токены и передаёт сцену выбранному провайдеру. Отключить автопоиск можно в настройках расширения; после выбора нужного подключения нажмите «Найти NPC в сцене» для ручного запуска.

Распознавание может ошибаться и зависит от модели. Найденных участников можно убрать или снять галочки. При сбое поиска мини-чат остаётся доступен, NPC можно добавить вручную. Распознавание не добавляет реплики ни в интервью, ни в основной чат. Пока оно выполняется, отправка вопроса временно недоступна. Старые интервью можно дополнить кнопкой «Найти NPC в сцене».

### Телефон

Кнопки создаются без ожидания наведения мыши. Поддерживаются перерисованные темой кнопки, полноэкранное окно на узком экране, изменение высоты при появлении клавиатуры и запасное открытие при отсутствии/ошибке `showModal()`. Клавиатура не вызывается автоматически при открытии на сенсорном устройстве. Если кнопки у сообщений скрывает тема, используйте кнопку в настройках расширения.

## Отдельное подключение / прокси

В окне есть список «Подключение для интервью»:

- **Основное подключение SillyTavern** использует `generateRaw` и текущий API.
- **Сохранённый профиль Connection Manager** использует `ConnectionManagerRequestService.sendRequest`: модель, API, пресет и прокси профиля, без переключения основного подключения.

Чтобы использовать отдельный прокси:
1. Настройте нужный API, модель, ключ и прокси штатными средствами SillyTavern.
2. Сохраните отдельный профиль Connection Manager, включив необходимые параметры (в том числе прокси).
3. Верните основное подключение для сюжетного чата.
4. Выберите сохранённый профиль в окне интервью. При необходимости нажмите «Обновить список подключений».

Требуется версия SillyTavern, предоставляющая этот API, и включённый Connection Manager. Не все типы профилей поддерживаются штатным сервисом. При недоступном/удалённом профиле показывается ошибка, **скрытого переключения на основной API нет**. Расширение не хранит копии ключей или реквизиты прокси, только ID профиля. При выборе другого провайдера контекст интервью передаётся этому провайдеру.

## Установка и обновление

Рабочая копия: `C:\Users\diox3\.cline\data\workspaces\chat\behind-the-scene-mini-chat`.

Сделайте резервную копию старого расширения и чатов. Обновите расширение вручную из `https://github.com/diox3xin/behind-the-scene` через меню SillyTavern. Для ручного копирования замените файлы **в существующей установленной папке** расширения следующими файлами из рабочей копии:

- `index.js`
- `interview-core.mjs` (новый файл, обязателен)
- `style.css`
- `manifest.json`

Не запускайте одновременно старую и новую копии: они используют один ключ настроек. Для установки в новую папку используйте штатный каталог сторонних расширений вашей установки. Сборка и установка npm-зависимостей не нужны.

После обновления перезагрузите страницу с Ctrl+F5. На телефоне закройте вкладку и откройте снова; при старой версии в логе очистите кэш сайта. Ожидаемый лог: `[Behind the Scene] Mini-chat v2.1.0 loaded`.

`auto_update` выключен. Обновляйте расширение вручную; если вы меняли код самостоятельно, сохраните копию изменений.

## Сохранение и безопасность

- Интервью хранятся в `chatMetadata['behind-the-scene'].sessions`, сохранение идёт через штатный API метаданных чата.
- Старые сохранённые интервью мигрируют в мини-чаты при чтении. Исходный массив `history` остаётся резервной копией. Данные, которые старая версия не сохранила на сервере, восстановить нельзя.
- При смене чата или закрытии окна поздний ответ не попадёт в другой чат. Для профильного запроса отправляется сигнал отмены. Основной `generateRaw` не принимает отдельный сигнал: закрытие отбрасывает результат, но сервер может закончить запрос и списать токены. До окончания запроса повторная генерация интервью заблокирована.
- При ошибке API история не изменяется, вопрос остаётся в поле для повторной отправки. При закрытии несохранённый черновик вопроса теряется.
- Не запускайте генерацию основного чата параллельно интервью: штатные генераторы могут разделять временные настройки. Уже идущая генерация основного чата блокирует отправку интервью.
- Пробная сборка промпта (`dryRun`) больше не включает блокировку «Сначала дождитесь ответа в основном чате». Окончание и остановка настоящей генерации снимают блокировку.
- Вывод текста использует DOM/textContent, а не HTML модели. Действия в `*звёздочках*` отображаются курсивом.

Генерация изображений отложена. Интеграция с `haruspics-naistera` в эту версию не входит.
